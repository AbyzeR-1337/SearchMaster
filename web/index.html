    Облачный поиск (GitHub)

    Нужен, чтобы запускать облачный поиск прямо отсюда и искать по коду на GitHub. Создать токен: Fine-grained, доступ только к репозиторию SearchMaster, права Actions: Read and write. Без токена облачный поиск запускается через issue на GitHub.
