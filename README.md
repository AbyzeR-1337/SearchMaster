# SearchMaster

Программа, которая по одному запросу (тема или название игры) прочёсывает интернет и собирает **всё, что удаётся найти**: статьи и вики, скриншоты и арты, трейлеры и геймплей, исходный код и репозитории, файлы (мануалы, PDF, архивы, форматы данных), обсуждения, архивные копии сайтов и новости/патчи. Потом она **анализирует** собранное: отсеивает шум, ранжирует, определяет движок, платформы, разработчика, ключевые слова, хронологию — и делает удобный интерактивный отчёт.

```
python -m searchmaster "Half-Life 2"
```

## Возможности

**24 источника**, опрашиваются параллельно:

| Что ищем | Источники |
|---|---|
| Веб-поиск | Bing, DuckDuckGo, *Brave Search API*, *Google Programmable Search*, *ваш SearXNG* |
| Вики и справка | Википедия (на нескольких языках), Fandom-вики, PCGamingWiki |
| Игры | Steam: карточка игры, официальные скриншоты 1920×1080, трейлеры, разработчик, патчноуты |
| Исходный код | GitHub (репозитории, topics, *поиск по коду с токеном*), Sourcegraph (строки кода по миллионам репозиториев), GitLab, Codeberg, npm, crates.io |
| Скриншоты и видео | YouTube, Bing Images, Wikimedia Commons, Openverse, Reddit (картинки и галереи) |
| Обсуждения | Reddit, Hacker News, Stack Exchange (gaming, gamedev, reverseengineering, stackoverflow) |
| Архивы и история | Internet Archive (с полным списком файлов в найденных коллекциях), Wayback Machine (старые версии официального сайта), OpenAlex (научные работы) |

*Курсивом* — источники, которым нужен бесплатный ключ (см. ниже). Без ключей работают все остальные.

**Как программа «додумывает» поиск:**

1. **План запросов.** Одна тема разворачивается в десятки целевых запросов по аспектам: `общее`, `скриншоты`, `видео`, `код`, `файлы`, `обсуждения`, `техническое` (движок, форматы файлов, реверс-инжиниринг, датамайн), `история` (бета, вырезанный контент, прототипы), `новости` — на русском и английском, с операторами `filetype:pdf`, `site:github.com` и т. п. Названия вида `S.T.A.L.K.E.R.:` автоматически переводятся в удобную для поисковиков форму.
2. **Раунд 1.** Все источники опрашиваются параллельно с вежливыми паузами для каждого сайта.
3. **Раунд 2 — «снежный ком».** Из найденного извлекаются новые зацепки: разработчик, связанные названия, персонажи, частые словосочетания — и по ним выполняется второй круг поиска. Найденный официальный сайт отправляется в Wayback Machine, найденные фан-вики — в поиск по Fandom.
4. **Глубокий анализ.** Лучшие страницы скачиваются и разбираются: текст, все изображения (с отсевом иконок и элементов интерфейса), ссылки на файлы, блоки кода, оглавление. У GitHub-репозиториев читается README и дерево файлов — по нему определяется движок/технологии (Unity, Unreal, Godot, Source…). С `--crawl-depth 1` программа ещё и переходит по релевантным ссылкам.
5. **Анализ и фильтр шума.** Дубликаты склеиваются (в т. ч. зеркала с одинаковым текстом). Релевантность считается по BM25, точному совпадению названия, «тематическому контексту» (слова, которые обычно окружают тему — так «Half-Life 2» отделяется от периода полураспада), популярности (звёзды, просмотры, голоса) и числу источников, подтвердивших результат.
6. **Отчёт:** интерактивный HTML, Markdown и полный JSON. По желанию — **скачивание** найденного и **ИИ-сводка** через Claude.

## Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/AbyzeR-1337/SearchMaster.git
cd SearchMaster
pip install -r requirements.txt
# или как команду:  pip install -e .   →  searchmaster "запрос"
# для ИИ-анализа:    pip install anthropic
```

`lxml` необязателен: без него программа сама переключается на встроенный HTML-парсер Python.

## На телефоне

У программы есть мобильный веб-интерфейс: поле поиска, выбор глубины («Быстро / Обычно / Глубоко»), живой прогресс с кнопкой «Остановить», история отчётов. Отчёт тоже адаптирован под телефон: вкладки листаются пальцем, скриншоты идут галереей в два столбца, скачанные файлы открываются прямо из отчёта.

```bash
python -m searchmaster --web
```

Откроется браузер с адресом `http://127.0.0.1:8000/`. В меню браузера нажмите **«Добавить на главный экран»** — появится иконка SearchMaster, и интерфейс будет открываться как отдельное приложение.

### Android — всё работает прямо на телефоне

1. Установите **Termux** из [F-Droid](https://f-droid.org/packages/com.termux/) (версия из Google Play устарела).
2. Откройте Termux и выполните одну команду:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/AbyzeR-1337/SearchMaster/main/termux-install.sh | bash
   ```
3. Запускайте: `searchmaster --web` — браузер откроется сам.

Полезно знать:
* Чтобы отчёты и скачанные картинки были видны в «Файлах»/«Галерее»: `termux-setup-storage`, затем `searchmaster --web --out ~/storage/downloads/SearchMaster`.
* Для долгого поиска («Глубоко») выполните `termux-wake-lock`, чтобы Android не усыпил Termux.
* С приложением **Termux:Widget** на рабочем столе появится ярлык «SearchMaster» (его создаёт установщик).
* Не закрывайте Termux, пока идёт поиск: сервер работает в нём.

### iPhone (и любой телефон) — через компьютер по Wi-Fi

На iOS нет полноценного Termux, поэтому проще запустить SearchMaster на компьютере и открыть его с телефона:

```bash
python -m searchmaster --web --host 0.0.0.0
```

Программа напечатает адрес вида `http://192.168.1.5:8000/?key=…` — откройте его в Safari на телефоне (компьютер и телефон должны быть в одной Wi-Fi-сети). Ключ `key` создаётся автоматически, чтобы чужие устройства в сети не могли пользоваться вашим поиском; после первого входа он запоминается. Если установить `pip install qrcode`, программа покажет QR-код — достаточно навести камеру.

Режим только консоли можно попробовать и прямо на iPhone в приложении **a-Shell** (`pip install requests beautifulsoup4`, затем `python3 -m searchmaster "запрос"`), но iOS приостанавливает фоновые приложения, поэтому веб-интерфейс там работает только пока a-Shell открыт.

## Примеры

```bash
# Всё по игре (по умолчанию: все аспекты, 2 раунда, глубокий разбор 25 страниц)
python -m searchmaster "Half-Life 2"

# Несколько названий сразу — так поиск охватит и русскоязычный интернет
python -m searchmaster "S.T.A.L.K.E.R.: Shadow of Chernobyl" -a "Сталкер Тень Чернобыля"

# Только код и техническая информация + скачать документы и картинки
python -m searchmaster "Doom 1993" --facets code,technical,files --download images,docs

# Скачать исходники найденных GitHub-репозиториев (zip) — не больше 10 штук
python -m searchmaster "OpenTTD" --facets code --download repos --max-downloads 10

# Максимально глубоко: переход по ссылкам, больше страниц, ИИ-сводка
python -m searchmaster "Hollow Knight" --deep 60 --crawl-depth 1 --ai

# Любая тема, не только игры
python -m searchmaster "Chernobyl disaster" --facets general,images,video,history,files

# Если не указать запрос — программа спросит его
python -m searchmaster
```

Список источников и их доступность: `python -m searchmaster --list-sources`.

## Параметры

| Параметр | Что делает |
|---|---|
| `-a, --alias` | альтернативное название (можно повторять) |
| `--lang en,ru` | языки запросов и Википедии (`en,ru,ja,…`) |
| `--facets` | аспекты поиска: `general,images,video,code,files,discussions,technical,history,news` |
| `--sources` / `--exclude` | использовать только эти / исключить эти источники |
| `--max-per-source 30` | результатов на один запрос к источнику |
| `--web-queries 14` | сколько расширенных запросов отправлять в каждый веб-поисковик |
| `--deep 25` | сколько лучших страниц скачать и разобрать целиком (`0` — выключить) |
| `--crawl-depth 0` | переходить по релевантным ссылкам с этих страниц на N уровней |
| `--rounds 2` | `2` — второй раунд «снежный ком», `1` — только основной |
| `--no-strict` | не отбрасывать результаты, где тема явно не упоминается |
| `--download` | скачать: `images,video,audio,docs,code,archives,gamedata,repos` или `all` |
| `--max-downloads 200`, `--max-file-mb 50` | ограничения на скачивание |
| `--ai`, `--ai-model`, `--ai-effort` | ИИ-анализ через Claude (см. ниже) |
| `-o results`, `--format html,md,json` | куда и в каких форматах сохранить отчёт |
| `--workers 8`, `--timeout 20`, `--delay 1.0` | параллельность, таймауты, пауза между запросами к одному сайту |
| `--no-cache` | не использовать кеш ответов (по умолчанию ответы кешируются на 24 ч в `.cache/`) |
| `--web`, `--host`, `--port`, `--key`, `--no-browser` | веб-интерфейс (см. «На телефоне») |

## Ключи API (необязательно, но расширяют поиск)

Создайте файл `.env` рядом с программой (пример — `.env.example`) или задайте переменные окружения:

| Переменная | Что даёт | Где взять |
|---|---|---|
| `GITHUB_TOKEN` | поиск **по коду** GitHub + выше лимиты | GitHub → Settings → Developer settings → Personal access tokens (хватит доступа только к публичным данным) |
| `BRAVE_API_KEY` | ещё один независимый веб-индекс | api.search.brave.com (есть бесплатный тариф) |
| `GOOGLE_API_KEY` + `GOOGLE_CSE_ID` | выдача Google | Google Programmable Search Engine + Custom Search API |
| `SEARXNG_URL` | метапоиск по десяткам движков через ваш инстанс SearXNG | свой сервер SearXNG с включённым JSON-форматом |
| `YOUTUBE_API_KEY` | YouTube через официальный API | Google Cloud Console → YouTube Data API v3 |
| `STACKEXCHANGE_KEY` | выше лимиты Stack Exchange | stackapps.com |
| `ANTHROPIC_API_KEY` | ИИ-анализ (`--ai`) | console.anthropic.com |

## ИИ-анализ (`--ai`)

С флагом `--ai` программа использует Claude (по умолчанию `claude-opus-5-5`) дважды:

* **до поиска** — подбирает альтернативные и оригинальные названия (японские, русские, аббревиатуры) и связанные термины, которые сразу идут в поиск;
* **после анализа** — пишет аналитическую сводку на русском со ссылками на источники: ключевые факты, где лучшие скриншоты, что есть в репозиториях, какие файлы и документы найдены, хронология и что искать дальше.

Нужны `pip install anthropic` и `ANTHROPIC_API_KEY`. Глубину рассуждений задаёт `--ai-effort` (`low` … `max`, по умолчанию `medium`). Запросы платные по тарифам Anthropic; если ключа нет, поиск просто идёт без ИИ.

## Что в отчёте

`results/<тема>-<дата>/report.html` — открывается в браузере, работает без интернета (кроме картинок-превью):

* сводные карточки: сколько найдено скриншотов, кода, файлов; статус каждого источника (наведите курсор — увидите ошибку);
* аналитика: разработчики, движки, платформы, хронология упоминаний, ключевые слова, связанные сущности, типы файлов, языки кода, топ доменов, подсказки «что ещё поискать»;
* вкладки: **Скриншоты** (галерея), **Видео**, **Код** (репозитории, фрагменты кода, структура репозиториев), **Файлы**, **Вики**, **Обсуждения**, **Страницы**, **Архивы**, **Новости**…;
* фильтр по тексту и сортировка по релевантности, дате или числу подтвердивших источников.

Рядом лежат `report.md` (то же текстом), `results.json` (всё в машиночитаемом виде) и, если включено скачивание, папка `downloads/` с `manifest.json` (URL, путь, размер, SHA-256 каждого файла).

## Ограничения и честная работа

* Программа представляется честным User-Agent'ом, соблюдает `robots.txt` при скачивании страниц и делает паузы между запросами к одному сайту.
* Некоторые сайты отвечают автоматическим клиентам капчей, `403` или `429` (так часто бывает с DuckDuckGo, Reddit, Wikimedia и PCGamingWiki при запуске с серверов). Такой источник **помечается в отчёте и пропускается** — программа не пытается обходить защиту. С домашнего IP обычно доступно больше; ключи API из таблицы выше дают стабильный доступ.
* Скачивание по умолчанию выключено; `all` никогда не включает исполняемые файлы; файлы больше `--max-file-mb` пропускаются.
* Используйте найденное законно: уважайте авторские права и правила сайтов. Программа ищет публично доступную информацию и не предназначена для получения пиратского или закрытого контента.

## Структура проекта

```
searchmaster/
  cli.py          командная строка
  engine.py       оркестрация: план → раунд 1 → «снежный ком» → глубокий анализ → фильтр → отчёт
  query.py        развёртка темы в запросы по аспектам и языкам
  sources/        24 источника (web, wiki, code, media, community, archive, games, misc)
  net.py          HTTP: повторы, паузы по сайтам, robots.txt, кеш, распознавание блокировок
  extract.py      разбор HTML: текст, изображения, файлы, код, ссылки
  crawler.py      глубокий анализ страниц и GitHub-репозиториев
  analyze.py      дедупликация, ранжирование, фильтр шума, движки/платформы/сущности/хронология
  ai.py           необязательный ИИ-слой (Claude)
  downloader.py   скачивание найденного
  report.py       HTML / Markdown / JSON
  web.py          мобильный веб-интерфейс (только стандартная библиотека Python)
termux-install.sh установка на Android одной командой
tests/            офлайн-тесты
```
