# 🔍 SearchMaster

Программа, которая по одному запросу (игра, тема, программа, персонаж…) **ищет всё по интернету**,
анализирует найденное и собирает понятный отчёт: тексты и вики, скриншоты и картинки, видео,
исходный код и репозитории, файлы и документы, моды, обсуждения, новости и патчноуты.

Работает **с телефона и с ПК через GitHub Actions** (ничего не надо устанавливать) или локально на компьютере.

## 🌐 Приложение по ссылке

### **https://abyzer-1337.github.io/SearchMaster/**

Открывается в любом браузере на телефоне и ПК. Вводите запрос, и поиск идёт прямо из браузера по 17 открытым
источникам, результаты появляются по мере поступления, обычно за 5–15 секунд. На телефоне приложение можно
добавить на главный экран («Поделиться → На экран „Домой“» или «Установить приложение»).

Что есть в приложении:
- **Точный поиск** (галочка «Точно» или запрос в кавычках): только результаты, где название встречается целиком.
- **«Что искать»**: только скриншоты, только видео, только исходный код, файлы, моды, обсуждения или статьи.
- **Несколько названий одной игры через « / »**: `Seven Souls Online / Martial Empires / 7Souls / 세븐소울즈`.
  Неоднозначное название уточняйте словами в скобках: `Седьмой элемент (игра, MMORPG, Nival)`. Тогда результат
  засчитывается, только если рядом есть одно из этих слов, и песня с тем же названием в выдачу не попадёт.
- **Режим «Максимум»**: больше всего результатов, запросы по каждому названию на его языке, второй уровень чтения
  страниц и **архивы старых официальных сайтов** из Wayback Machine (страницы, новости, скриншоты, документы).
  Сайты можно указать сами в поле «Сайты» (`7souls.ru, sevensoulsonline.com`), остальные находятся по названию.
- **«Мои темы»** на главном экране: закреплённые игры открываются в одно касание. Первая уже закреплена:
  Seven Souls Online / Martial Empires (глубокий точный поиск по всем её названиям).
- **Главное о теме** из Википедии и Wikidata: что это, разработчик, дата выхода, жанр, платформы, композитор и ссылки
  на Steam, GOG, PCGamingWiki, IGDB, MobyGames, Fandom-вики, сабреддит, официальный сайт.
- **Другие названия**: запрос на русском дополнительно ищется по английскому названию.
- Вкладки по категориям, фильтр, галерея с просмотром картинок, связанные темы (нажмите, чтобы уточнить поиск),
  статус каждого источника, выгрузка в JSON и CSV, ссылка на поиск (`?q=Hollow+Knight`).
- **Полный поиск в облаке** одной кнопкой: GitHub Actions добавит то, что браузер не умеет (скриншоты и трейлеры
  Steam, чтение страниц, скачивание файлов и исходников, AI-сводку). Готовые отчёты открываются прямо в приложении
  в разделе «Облачные отчёты».

**Включить один раз** (после слияния в `main`):
1. **Settings → Pages → Build and deployment → Source: «GitHub Actions»**.
2. **Actions → «🌐 Веб-приложение (GitHub Pages)» → Run workflow** (или любой push в `web/`).
   Через минуту ссылка выше заработает.

**Облачный поиск из приложения.** Без токена кнопка открывает на GitHub заполненную форму issue: нажмите «Create».
С токеном поиск запускается прямо из приложения, а прогресс виден на месте. Токен создаётся на
[github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new):
Fine-grained, доступ только к этому репозиторию, право **Actions: Read and write**. Вставьте его в ⚙️ настройки
приложения. Токен и ключи хранятся только в вашем браузере.

| 🎮 **Режим игры** | Сам узнаёт игру и берёт из Steam карточку (разработчик, дата, жанры, платформы), **официальные скриншоты**, трейлеры, новости и патчноуты, плюс фанатскую вики и моды |

| 🧠 **Анализ** | Убирает дубли, оценивает релевантность каждого результата и отсеивает мусор, выделяет связанные темы, строит хронологию и статистику (сайты, языки кода, типы файлов, лицензии, годы) |
| 📖 **Чтение страниц** | Открывает лучшие найденные страницы (с соблюдением `robots.txt`), берёт самый подходящий фрагмент текста и находит на них ссылки на файлы, картинки, репозитории и видео |
| 🔁 **Глубокий режим** | `deep`: дополнительные запросы по найденным темам (скриншоты, исходники, моды, саундтрек, гайды…) |
| 💾 **Скачивание** | Скриншоты, изображения, документы (PDF и т. п.), по желанию ZIP-архивы исходников популярных репозиториев. Есть лимиты размера, исполняемые файлы не качаются |
| 🤖 **AI-анализ** (необязательно) | С ключом `ANTHROPIC_API_KEY` Claude пишет сводку: главное, ключевые факты, хронология, где что искать, противоречия, что поискать дальше. Каждый факт со ссылкой на источник |
| 📄 **Отчёты** | `report.md` (читается прямо на GitHub и с телефона), интерактивный `report.html` (вкладки, фильтр, галерея, тёмная тема), `results.json`, `links.csv` (Excel) |

## 📱 Запуск с телефона

Сначала один раз: откройте вкладку **Actions** в репозитории и включите workflows, если GitHub попросит.

**Способ 1. Через issue (удобнее всего на телефоне)**
1. Приложение GitHub или браузер → репозиторий → **Issues → New issue → «🔍 Новый поиск»**.
2. Впишите запрос (например `Hollow Knight`), выберите режим и нажмите **Create**.
3. Через 1–5 минут в issue придёт комментарий с отчётом: главное, галерея скриншотов, ссылки по категориям.
   Уведомление придёт на телефон.

Повторить или уточнить поиск можно комментарием в любом issue:
```
/search Hollow Knight --deep
/search Celeste source code --sources=code
/поиск Ведьмак 3 --quick
```

**Способ 2. Кнопка Run workflow**
**Actions → 🔍 SearchMaster → Run workflow** → заполнить поля → **Run**.
Работает в браузере на телефоне и ПК; в приложении GitHub тоже есть, если ваша версия это поддерживает.

> Запускать поиск через issue и комментарии могут только владелец репозитория и соавторы,
> поэтому посторонние не потратят ваши минуты Actions.

## 💻 Запуск на ПК

**Через GitHub**: так же, как с телефона (Actions → Run workflow или issue).

**Локально** (нужен Python 3.10+):

```bash
git clone https://github.com/AbyzeR-1337/SearchMaster.git
cd SearchMaster
pip install -r requirements.txt

python -m searchmaster "Hollow Knight"                       # обычный поиск
python -m searchmaster "Hollow Knight" --mode deep --open     # глубокий + открыть отчёт в браузере
python -m searchmaster "Celeste" --sources code --code-zips 3 # только код + ZIP трёх топ-репозиториев
python -m searchmaster "квантовые компьютеры" --sources text  # не игра, а любая тема
python -m searchmaster --list-sources                         # какие источники доступны
```

Или проще:
- **Windows**: дважды щёлкните `search.bat`, введите запрос, отчёт откроется в браузере.
- **Linux / macOS / Android (Termux)**: `./search.sh "Hollow Knight"`.

Результаты сохраняются в `results/<дата>_<запрос>/`.

## ⚙️ Параметры

| Параметр | Значения | Что делает |
|---|---|---|
| `--mode` | `quick` / `normal` / `deep` / `max` | глубина: quick ≈ 10 результатов на источник без чтения страниц; normal ≈ 25 + анализ 25 страниц; deep ≈ 50 + доп. запросы + 60 страниц; max — всё сразу, до часа и больше |
| `--site` | `7souls.ru,sevensoulsonline.com` | официальные сайты, которые надо поднять из Wayback Machine |
| `--exact` | | точный поиск: только результаты с названием целиком |
| `--only` | `image`, `video`, `code`, `file`, `mod`, `discussion`, `text`, `audio` | искать только этот тип материалов |
| `--sources` | `all`, `game`, `code`, `media`, `files`, `text` или список | наборы источников; можно исключать: `game,-reddit` |
| `--langs` | `ru,en` | языки Википедии и вики |
| `--no-download` | | только ссылки, без скачивания |
| `--code-zips N` | 0–10 | скачать исходники N самых популярных репозиториев |
| `--images`, `--files` | число | сколько изображений / файлов скачивать |
| `--max-file-mb`, `--max-total-mb` | 25 / 400 | лимиты размера |
| `--min-score` | 0.12 | порог релевантности для отчёта |
| `--ai` | `auto` / `on` / `off` | AI-анализ (нужен ключ) |
| `--open` | | открыть HTML-отчёт после поиска |

## 🔑 Ключи (все необязательные)

Без ключей работают ~15 бесплатных источников. Ключи добавляют возможности.
Добавляются в **Settings → Secrets and variables → Actions → New repository secret**
(локально — переменные окружения, см. `.env.example`).

| Секрет | Что даёт | Где взять |
|---|---|---|
| `BRAVE_API_KEY` | **поиск по всему интернету** + картинки и видео (рекомендуется) | [api-dashboard.search.brave.com](https://api-dashboard.search.brave.com/) |
| `GOOGLE_API_KEY` + `GOOGLE_CSE_ID` | поиск Google по всему интернету + картинки | [Programmable Search](https://programmablesearchengine.google.com/) |
| `SEARXNG_URL` | ваш экземпляр SearXNG (метапоиск) | свой сервер с включённым JSON |
| `ANTHROPIC_API_KEY` | 🤖 AI-анализ найденного (Claude) | [console.anthropic.com](https://console.anthropic.com/) |
| `GH_SEARCH_TOKEN` | поиск **по коду** во всём GitHub | GitHub → Settings → Developer settings → Personal access token (только чтение) |
| `YOUTUBE_API_KEY` | видео YouTube | Google Cloud → YouTube Data API v3 |
| `RAWG_API_KEY` | база игр RAWG + скриншоты | [rawg.io/apidocs](https://rawg.io/apidocs) |
| `REDDIT_CLIENT_ID` + `REDDIT_CLIENT_SECRET` | посты Reddit | [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps) |
| `STACKEXCHANGE_KEY` | больше запросов к Stack Exchange | [stackapps.com](https://stackapps.com/apps/oauth/register) |

## 🧭 Как это работает

```
запрос → все источники параллельно → объединение дублей → оценка релевантности
      → другие названия (Википедия) → повторный проход по англоязычным источникам
      → распознавание игры (Steam) → связанные темы → [deep] доп. запросы
      → чтение лучших страниц (robots.txt) → новые ссылки на файлы/картинки/код
      → скачивание → [AI-анализ] → report.md / report.html / results.json / links.csv
```

```
searchmaster/
  sources/        источники: web, wiki, games, code, archives, media, community
  pipeline.py     весь процесс поиска
  analyze.py      дубли, релевантность, темы, альтернативные названия, статистика
  fetch.py        чтение страниц и поиск ссылок на них
  download.py     скачивание с лимитами
  ai.py           AI-сводка (Claude)
  report.py       отчёты; templates/report.html — интерактивный отчёт
  gh.py           разбор запроса из issue/комментария, оглавление результатов
web/              приложение по ссылке (GitHub Pages): engine.js — поиск и анализ в браузере, app.js — интерфейс
.github/workflows/search.yml   облачный поиск (GitHub Actions)
.github/workflows/pages.yml    публикация web/ на GitHub Pages
```

Тесты: `pip install pytest && python -m pytest -q` и `node --test tests/web/engine.test.mjs`.
Локально приложение запускается так: `cd web && python -m http.server 8000`, затем откройте http://localhost:8000.

## ⚖️ Честная игра

- Используются только **официальные API** и открытые страницы. Капчи и защита от ботов не обходятся;
  программа представляется честным User-Agent и соблюдает `robots.txt` и лимиты сайтов.
- Не скачиваются исполняемые файлы (`.exe`, `.apk`, `.msi` и т. п.), а программы и игры с archive.org
  исключены из поиска: там часто лежат нелегальные копии.
- Найденные материалы принадлежат их авторам. Проверяйте лицензии (они указаны в отчёте, где известны)
  и уважайте авторские права.
